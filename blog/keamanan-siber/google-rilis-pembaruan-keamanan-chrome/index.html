Google Rilis Pembaruan Keamanan Chrome Segera Perbarui Dan Restart Browser.

14 September 2026
⏱️ Dibaca 3 menit

NewsBackMedia - Google baru saja merilis pembaruan keamanan Chrome untuk menambal celah yang sudah mulai dieksploitasi di dunia maya. Pengguna diminta segera memperbarui sekaligus me-restart browser agar perlindungan aktif.

Dalam rilis terbarunya, Google memperbaiki total 26 celah keamanan. Dua di antaranya dikategorikan sebagai kerentanan kritis jenis use-after-free yang berpotensi menyebabkan crash dan eksekusi kode.

Tidak lama setelah itu Google kembali merilis patch tambahan untuk mesin JavaScript V8. Kerentanan tersebut tercatat dengan kode CVE-2026-85046 dan memiliki tingkat keparahan tinggi.

Menurut laporan Google, eksploit untuk celah V8 ini sudah beredar. Penyerang dapat memanfaatkan halaman HTML yang dirancang khusus untuk menjalankan kode arbitrer di dalam sandbox Chrome.

Karena celah sudah aktif digunakan, HKCERT menilai tingkat risikonya secara keseluruhan berada pada kategori sangat tinggi. Pengguna disarankan tidak menunda pemasangan pembaruan.

Setelah memasang versi terbaru, nomor build Chrome akan berubah menjadi 152.0.7977.82/.83 untuk pengguna Windows dan Mac. Sementara pengguna Linux akan mendapatkan versi 152.0.7977.82.

Untuk memperbarui secara manual, buka menu tiga titik lalu masuk ke Settings > About Chrome. Jika pembaruan tersedia, Chrome akan otomatis mengunduh dan meminta Anda me-restart.

Langkah restart penting agar semua tambalan benar-benar diterapkan. Pembaruan otomatis kadang tertunda jika browser jarang ditutup atau proses unduhan mengalami gangguan.

Dua celah kritis lainnya adalah CVE-2026-84353 pada fitur Shared Tab Groups dan CVE-2026-84352 pada WebGL. Keduanya memungkinkan penyerang dari jarak jauh menjalankan kode di luar sandbox melalui halaman HTML yang dimodifikasi.

Kerentanan yang memungkinkan eksekusi kode dari jarak jauh menjadi target utama peretas. Aktivitas sederhana seperti mengunjungi situs berbahaya bisa dimanfaatkan untuk mengeksekusi kode langsung ke sistem operasi perangkat korban.
